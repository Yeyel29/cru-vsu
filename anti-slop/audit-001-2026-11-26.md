# Antislop Audit: `src/app/page.tsx`

- **Date:** 2026-11-26
- **Mode:** After (`antislop` + `antislop-ui`)
- **Target:** `src/app/page.tsx` (cross-checked against `DESIGN.md` and `src/app/globals.css`)
- **Status:** Findings 1–4 (HIGH) fixed per user approval; findings 5–10 (MEDIUM/LOW) untouched pending approval.

## Numbered Findings

1. **[HIGH] — R-02 (Copywriting: Em Dashes)** — `src/app/page.tsx#L60`, `#L128`, `#L183`: UI copy contains four em dash (`—`) characters (`relationships—where`, `discipler—their spiritual mom or dad—to`, `college—we'd`), which are forbidden under Hard Gate R-02.
2. **[HIGH] — R-25 (Color Contrast)** — `src/app/page.tsx#L118`, `#L153`, `#L173`: Section index labels (`01 · Spiritual Family Tree`, `02 · Campus Ministry`, `03 · Get Connected`) use 12px (`text-xs`) `text-cru-gold-hover` (`#eaa400`) on `#ffffff` / `#fafafa`, giving ~2.14:1 contrast (below the 4.5:1 WCAG AA minimum for normal text).
3. **[HIGH] — R-27 (UI States: Loading & Error)** — `src/app/page.tsx#L27-L30`: Server data fetching (`Promise.all([fetchDiscipleshipGraphData(), fetchActiveProjects()])`) has no error handling or fallback UI, and `src/app/` has no `error.tsx` or `loading.tsx` / `Suspense` boundary.
4. **[HIGH] — R-39 (Accessible Semantics & Interaction Affordances)** — `src/app/page.tsx#L71`, `#L81`, `#L136`, `#L174`: Decorative Lucide icons (`GitBranch`, `ArrowRight`, `Sparkles`) inside links and headings lack `aria-hidden="true"`.
5. **[MEDIUM] — R-09 (Badges: Eyebrow Pill Above H1 & Decorative Dot)** — `src/app/page.tsx#L45-L48`: A bordered pill badge with a non-functional gold status dot sits directly above the `<h1>` (`Cru · Visayas State University`), duplicating campus context without marking a live state (and is not specified in `DESIGN.md`).
6. **[MEDIUM] — R-04 (Icons: Generic AI Icon)** — `src/app/page.tsx#L174`: Uses `<Sparkles />` beside `03 · Get Connected`, a generic AI-slop glyph with no written content-relevance reason (sections `01` and `02` use no icon).
7. **[MEDIUM] — R-08 (Button Arrows)** — `src/app/page.tsx#L81`: Places a right-pointing `<ArrowRight />` on the `Campus Activities` link even though `href="#projects"` scrolls downward on the same page.
8. **[MEDIUM] — R-06 (Typography: Wide-Tracked Uppercase Mono)** — `src/app/page.tsx#L45`, `#L91`, `#L99`, `#L107`, `#L118`, `#L153`, `#L173`: Applies `font-mono uppercase tracking-wider` / `tracking-widest` across the hero eyebrow, metric labels, and section indices without a written typographic purpose beyond `DESIGN.md` section indices.
9. **[LOW] — R-05 (Layout & Page Structure: Uniform Section Rhythm)** — `src/app/page.tsx#L117`, `#L152`, `#L170`: All three lower sections use identical `py-24` vertical padding, and sections 2 and 3 repeat the same header stack (`01/02` mono eyebrow + `h2` + `p` + component).
10. **[LOW] — R-15 (CTA Copy)** — `src/app/page.tsx#L73`, `#L80`: `"Explore Discipleship Tree"` opens with the generic `"Explore"` verb, and `"Campus Activities"` is a noun phrase rather than a specific action CTA.
